src.reproduce#

Helpers for reproducing Bruno, Islam & Niet, “Storage in long-term energy planning models with temporal aggregation” (Environ. Res. Commun., ERC-105849) with this repository.

Used by reproduce_study.ipynb and automation.py. Every model run goes through main.py unchanged, so the notebook exercises exactly the code path that produced the published numbers.

Naming: the formulation called Novo in the paper is implemented in Model_Cluster.

src.reproduce.soc_violations(soc, upper: float, lower: float = 0.0, tol: float = 1e-09) → dict[source]#

Count bound violations of a storage trajectory.

strict: SoC > upper + tol or SoC < lower - tol (physically infeasible states). at_or_beyond: SoC >= upper - tol or SoC <= lower + tol (includes states exactly on a bound, which are feasible). The R2 draft’s ‘183 h above’ for wind equals the at_or_beyond count.

src.reproduce.hourly_trajectory(results_dir, scenario: str, formulation: str, h: int) → numpy.ndarray[source]#

8760-h storage trajectory used for the fidelity metrics.

Novo and Kotzur: chronological block series (Kotzur reconstructed), held over each block. Welsch: reconstructed series in its native grouped day-type order, as plotted by graph_generator.py. Niet: representative blocks held for their year-split duration.

src.reproduce.rainflow_cycles(series) → float[source]#

Equivalent full cycles by rainflow counting (ASTM E1049-85 three-point method).

Half cycles count 0.5. Returns the total number of (equivalent full) cycles.
