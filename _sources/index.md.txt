## At a glance

```bash
git clone https://github.com/DeltaE/storage-in-OSeMOSYS.git
cd storage-in-OSeMOSYS
make setup && conda activate storage_osemosys
python main.py
```

See {doc}`quickstart` for what this does and where the results go.
