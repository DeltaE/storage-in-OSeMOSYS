# Modelling workflow

<p class="page-intro">
This section takes you from a fresh copy of the code to solved models. You set up the software
once, run one command, and the pipeline picks representative days, builds an OSeMOSYS model for
each storage formulation, solves them and saves the results. After that, you change a single
configuration file to try your own scenarios. Follow the cards in order the first time.
</p>
