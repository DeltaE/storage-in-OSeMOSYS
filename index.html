Storage in OSeMOSYS#

Storage formulations for long-term energy planning models with temporal aggregation — four ways to represent energy storage in OSeMOSYS, compared side by side.

01 Concept Why storage is hard to model under temporal aggregation, and the four formulations compared. 02 Modelling workflow Installation, quickstart, pipeline steps, configuration and assumptions. 03 Results Reproduce the published study, output files and how to analyse them. 04 API Reference for the src package, generated from the source code.

At a glance#

git clone https://github.com/DeltaE/storage-in-OSeMOSYS.git
cd storage-in-OSeMOSYS
make setup && conda activate storage_osemosys
python main.py

See Quickstart for what this does and where the results go.

Citation#

Borba, B., Islam, M. E., & Niet, T. Storage in Long-Term Energy Planning Models with Temporal Aggregation: Best Practices and Algorithms. Environmental Research Communications (2026).
