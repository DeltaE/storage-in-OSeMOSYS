Module Overview#

The src package holds every step of the workflow. workflow/main.py calls them in order (see Workflow Guide); src.reproduce wraps whole runs for the notebook and the batch runner. Signatures and docstrings for every function are in the generated reference (src).

Most functions take file paths and plain Python values, read or write OSeMOSYS-style CSV files (REGION, …, VALUE) and return the path they wrote.

Clustering#

Function

Module

What it does

cluster_data(capacity_factor_path, demand_profile_path, n_clusters, random_state=0, n_init=1)

src.cluster

k-means on daily 48-value vectors (24 scaled CF + 24 scaled demand values). Returns the sorted representative days and, for each of the 365 days, the representative day that stands in for it.

 
from src.cluster import cluster_data

days, sequence = cluster_data("data/timeseries/CapacityFactor_Wind.csv",
                              "data/timeseries/SpecifiedDemandProfile.csv", n_clusters=4)
